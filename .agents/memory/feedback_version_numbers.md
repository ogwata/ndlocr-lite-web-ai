---

機能追加・修正をコミットする際、バージョン番号の更新を必ず行うこと。
ユーザーはバージョン番号を目安にテスト・確認を行っている。

**Why:** ユーザーから複数回指摘を受けている。バージョン番号が古いままだとどのビルドをテストしているか分からなくなる。

**バージョニングルール:**
- 機能追加 → 小数点以下1桁を更新（例: v0.6.x → v0.7.0）
- 修正（バグ修正等） → 小数点以下2桁を更新（例: v0.6.1 → v0.6.2）

**How to apply:** バージョン更新時に以下3箇所を確認・更新する:
- `src/components/layout/Header.tsx` のUIバッジ
- `package.json` の version フィールド
- `src/utils/exportTEI.ts` のTEIメタデータ内 version 属性
判断に迷うときはユーザーに次のバージョン番号を確認する。
