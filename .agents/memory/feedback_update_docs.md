name: ドキュメント更新を自主的に行う
description: コード変更時にCLAUDE.md、README.md、開発計画書への反映を言われなくても自主的に行う
type: feedback
---

コード変更をコミットする際、関連するドキュメントの更新も自主的に行うこと。

**Why:** ユーザーから「言わないでもやってください」と指摘を受けた。毎回ドキュメント更新を催促させるのはユーザーの負担。

**How to apply:** 機能追加・変更・削除のコミット時に、以下のドキュメントを確認し必要に応じて更新する:
- CLAUDE.md（技術仕様、ディレクトリ構成、UI設計仕様）
- README.md（特徴、技術スタック、変更履歴）
- docs/NDLOCR-Lite-Web-AI-開発計画書.md（技術スタック、UI設計）
ドキュメント更新は同じコミットに含めるか、直後の専用コミットで行う。
