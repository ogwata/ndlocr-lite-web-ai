# このリポジトリの記憶

- このリポジトリの記憶は `.agents/memory/` にある。Claude Code も同じフォルダを読み書きしている。
- 作業を始める前に、目次 `.agents/memory/MEMORY.md` を読む。いまの作業に関わる項目があれば、そのファイルも開いて読む。
- 小形さんから指摘・訂正・好みを受けたら、その場で `.agents/memory/` に1件1ファイルで書き、目次 `MEMORY.md` に1行足す。
  - ファイルの先頭には、既存のファイルと同じ形の YAML を置く（`name`、`description`、`metadata` の下の `type`。`type` は feedback・project・reference・user のどれか）。
  - 目次の行は `- [題](ファイル名.md) — 1行の説明` の形にする。
- すでにある記憶と同じ趣旨なら、新しいファイルを作らず、そのファイルを直す。
